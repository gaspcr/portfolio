Clínica dermatológica con 14 especialistas. El proyecto fue mucho más que un sitio: se conectó la web, la tienda, la agenda y el sistema interno de la clínica (FileMaker) para que todo funcione como un solo ecosistema.

Agendamiento online con pago

Plugin WordPress a medida para reservar horas de estética directo contra la agenda de FileMaker, con pago vía Shopify y confirmación automática por webhook.

  • PHP
  • WordPress

02

Stock sincronizado Shopify ↔ FileMaker

Servicio bidireccional: el inventario de la clínica alimenta la tienda y cada venta online descuenta stock en el sistema interno. Con reintentos, control de rate limit y logs.

  • Python
  • Shopify Admin API
  • Railway
03

Asistente de WhatsApp para el equipo

Bot para médicos y gerencia: agenda del día, información de pacientes y boxes, con permisos por rol y verificación segura de mensajes.

  • WhatsApp Business API
  • FastAPI
  • Redis

Reportería automática

Sincronización periódica de la agenda de FileMaker a Google Sheets para que gerencia tenga datos al día sin exportar nada a mano.

  • Python
  • Google Sheets API
  • Worker
